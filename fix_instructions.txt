# TZ Tourism Radar SaaS - Startup & Issue Fix Guide

## ✅ RESOLVED: Application Startup Issues

### Problem: Path Errors When Starting Backend
**Error:** `cd tz-radar-saas/backend` failed when run from `tz-radar-saas/frontend` because it created invalid path `C:\Tanzania-Russia\tz-radar-saas\frontend\tz-radar-saas\backend`

**Solution:** Created startup scripts that handle directory changes automatically:
- `start_backend.bat` - Starts FastAPI backend on port 8000
- `start_frontend.bat` - Starts Next.js frontend on port 3000

### How to Start the Application
**Option 1 (Recommended):** Double-click the batch files in File Explorer
- Run `start_backend.bat` first (from project root)
- Run `start_frontend.bat` second (from project root)

**Option 2:** From PowerShell in project root (C:\Tanzania-Russia):
```powershell
.\start_backend.bat
```
Then in another terminal:
```powershell
.\start_frontend.bat
```

**Access the Application:**
- Frontend: http://localhost:3000
- Backend API: http://localhost:8000
- API Health: http://localhost:8000/health

## ⚠️ ACTIVE ISSUES REQUIRING CONFIGURATION

### 1. OpenAI API Quota Exceeded
**Error:** `Error code: 429 - {'error': {'message': 'You exceeded your current quota', 'type': 'insufficient_quota'}}`

**Impact:** AI translation and executive summary generation fail

**Solution:**
1. Go to https://platform.openai.com/account/billing
2. Add payment method or purchase credits
3. Check API key in `tz-radar-saas/backend/.env`

### 2. Exa API Rate Limit Errors
**Errors:**
- `HTTP 429` - Rate limit exceeded
- `HTTP 405` - Method not allowed
- `Connect Timeout Error` - Service unavailable

**Impact:** Web search functionality limited

**Solution:**
1. Check Exa API key in `tz-radar-saas/backend/.env`
2. Verify API subscription status at https://exa.ai
3. Implement exponential backoff in scanner code (line ~399-407)
4. Consider caching search results to reduce API calls
